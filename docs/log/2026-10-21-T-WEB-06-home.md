## What was built

The home page now renders the ten sections stored in `content/pages/home.json`: hero with doctor and department search, quick actions, departments, centres, featured doctors, packages, branches, the guide teaser, articles and the emergency band. Every page section type in the catalog (17) has a renderer in the section registry, so the other content pages (about, guide, emergency, portal) can be built from the same parts. Images are token-colored placeholder slots until photography or AI images arrive.

## Decisions applied

- Client components never import the content module (it would ship all JSON to the browser); they get plain props, and shared text helpers live in `normalize.ts`.
- A display utility on an element that also gets `inline-flex` or `flex` from a shared class string is unreliable (CSS order decides); responsive hiding uses a wrapper element instead.
- Doctor leave badges use the build date (static pages); WEB-B will render them per request or revalidate daily.
- The `stats` section on About stays hidden in WEB-A (P-032: no fabricated figures).

## How to debug

- A section does not appear: check `hidden` in the page JSON and that the type has a case in `registry.tsx`.
- A responsive `hidden` class has no effect on a button-styled link: wrap the link instead.
